# Procedural Bill Calculator

A **console-based bill calculator** built using **procedural programming** in Python.  
It allows users to order items from a menu, calculates totals by category, and generates a receipt.



## Features

- Simple **text-based ordering system**
- Supports **Kota**, **refreshments**, and **chips**
- Accepts orders with **quantities**
- Calculates totals by category and overall total
- Generates and saves a **receipt** with timestamp (`receipt.txt`)
- Handles **invalid input** gracefully
