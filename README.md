# Flask Contact Form

A simple **contact form web application** built with **Flask** that allows users to send messages directly to your Gmail account.


## Features

- Simple contact form with fields: Name, Email, Message
- Sends messages via **Gmail SMTP**
- Displays success or error messages using Flask `flash`
- Redirects back to the form after submission

---

## Tech Stack

- **Backend**: Flask  
- **Frontend**: HTML templates (rendered via Flask)  
- **Email**: Gmail SMTP  
- **Language**: Python 3.10+
